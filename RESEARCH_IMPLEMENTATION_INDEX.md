## Condition-level traceability

Every retained final condition follows the same evidence path:

```text
prepared dataset
    → regime-specific prompt artefact
    → raw generation JSONL
    → automatic detailed and summary evaluation
    → code-grounded detailed and summary evaluation
    → row-count, schema, checksum, and sample-ID validation
    → clean_full_results.csv
    → Chapter 5 tables and figures
```

The stable `sample_id` is the primary join key across prompt, generation, automatic-evaluation, code-grounded-evaluation, and result-assembly artefacts. A condition is treated as complete only when the raw generation, automatic detailed evaluation, and code-grounded detailed evaluation contain the expected 400 unique sample identifiers and the required provenance is retained.
