# Human Evaluation Evidence

This folder contains publication copies of the available human-evaluation workbooks and extracted summary tables.

## Publication handling

- Workbook contents were preserved for evaluator review.
- Workbook metadata creator/last-modified fields were redacted in the public copies.
- Local absolute workspace paths in workbook cells were replaced with `${LOCAL_WORKSPACE}`.
- Original and public SHA-256 checksums are recorded in `human_evaluation_workbook_manifest.csv`.
